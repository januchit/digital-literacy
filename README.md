# เตรียมตัวทดสอบทักษะดิจิทัล (Digital Literacy)

เว็บไซต์คู่มืออ่าน + แบบทดสอบโต้ตอบ สำหรับเตรียมตัวสอบทักษะดิจิทัล ครบทั้ง **7 บทเรียน**

1. Technology Basics — พื้นฐานเทคโนโลยี
2. Digital Citizenship — การเป็นพลเมืองดิจิทัล
3. Information Management — การจัดการข้อมูล
4. Content Creation — การสร้างสรรค์เนื้อหา
5. Communication — การสื่อสาร
6. Collaboration — การทำงานร่วมกัน
7. Safety and Security — ความปลอดภัยและความมั่นคง

## คุณสมบัติ
- **โหมดอ่าน** — แสดงคำถาม เฉลย และคำอธิบายครบทุกข้อ
- **โหมดทำแบบทดสอบ** — เลือกบท ทำ quiz แล้วระบบตรวจคะแนนพร้อมเฉลย
- เป็นเว็บไฟล์เดียว (static) ไม่ต้องใช้เซิร์ฟเวอร์ ใช้ได้บนมือถือและคอมพิวเตอร์

## ไฟล์
- `index.html` — หน้าเว็บและตรรกะทั้งหมด
- `data.js` — เนื้อหาคำถาม/เฉลยทั้ง 7 บท
- `.nojekyll` — บอก GitHub Pages ไม่ต้องประมวลผลด้วย Jekyll

## วิธีเผยแพร่ด้วย GitHub Pages
1. Push โฟลเดอร์นี้ขึ้น repository บน GitHub
2. ไปที่ **Settings → Pages**
3. เลือก Source = `Deploy from a branch` → Branch = `main` → โฟลเดอร์ `/ (root)` (หรือ `/website` ตามที่วางไฟล์)
4. กด Save แล้วรอสักครู่ เว็บจะออนไลน์ที่ `https://<username>.github.io/<repo>/`

## เปิดดูในเครื่อง
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย
